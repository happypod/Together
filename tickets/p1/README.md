# P1 Tickets

P1은 MVP 운영 효율을 높이는 확장 작업이다. P0 흐름이 동작한 뒤 착수한다.

## Tickets

- `T-031-mobility-calendar.md`: 이동 캘린더 월간, 주간, 일간 보기
- `T-036-incident-complaint-input.md`: 사고 및 민원 입력
- `T-037-mobile-link-input-forms.md`: 모바일 링크형 입력폼
- `T-045-community-fund-record.md`: 상생기금 기록
- `T-046-monthly-settlement-table.md`: 월별 정산표
- `T-052-monthly-operation-report.md`: 월간 운영리포트
- `T-053-satisfaction-statistics.md`: 만족도 통계
- `T-054-linker-activity-statistics.md`: 동행링커 활동통계
- `T-055-csv-download.md`: CSV 다운로드
- `T-064-mobile-screen-qa.md`: 모바일 화면 검증
